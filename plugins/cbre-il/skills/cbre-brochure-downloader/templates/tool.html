Brochure Downloader — __CLIENT__

1 Set your browser to download PDFs

By default Chrome and Edge open a PDF instead of saving it. None of these servers force a download, so without this change the run produces no files at all.

  1. Chrome: paste chrome://settings/content/pdfDocuments into the address bar, then choose Download PDFs.
  2. Edge: paste edge://settings/content/pdfDocuments into the address bar, then turn Always download PDF files on.

Change it back afterwards if you prefer reading PDFs in the browser.

Test one brochure first, and read the result. This opens a small download window and sends one brochure to it. Your browser will ask to allow a popup — allow it.
  • The window stays blank and a PDF appears in your Downloads folder — the setting is applied. Carry on to step 2.
  • The brochure appears on screen in that window — the setting has not taken effect. Re-check it, reload this page, and test again.

2 Download the brochures

Each brochure is sent to the small download window in turn. Keep that window open — closing it pauses the run. The page cannot tell whether a download finished, because the browser reports nothing back for cross-origin downloads, so this says sent rather than done. Step 3 is what actually verifies the files.
