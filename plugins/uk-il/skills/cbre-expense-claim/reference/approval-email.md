# The approval email

Written after the report is submitted, asking the line manager to approve it.
This is the user's own voice, captured verbatim from an email they wrote for one
of these reports. Match it. Do not improve it.

## Template

```
Subject: <trip> expenses for approval

Hi <manager first name>,

Could you please let me know if you approve attached expenses covering the
<cities> trip for <client>.

Total: £<total>

The two largest items are:

* £<amount>, <what it was> - <one clause, only where the size needs explaining>
* <amount>, <what it was>

The rest is <sweep-up list>. Receipts are attached.

Happy to talk anything through.

Thanks,

<your first name>
```

## The rules behind it

- **Short.** Under 100 words. One ask, the number, the two big items, a sweep-up
  line, sign off.
- **Ask, do not announce.** "Could you please let me know if you approve", not
  "I have submitted X for your approval".
- **Cities, then client.** `the Rotterdam and Venlo trip for Hillwood`.
  Name every city that carries real spend, and name the client the trip was for.
- **Total on its own line**, as `Total: £1,082.40`. Nothing else on that line.
- **Two largest items, amount first**, in the currency the line is actually
  claimed in. A EUR line stays in euros; do not convert it to sterling to make
  the list sort cleanly.
- **Explain only what looks odd.** The car hire gets `One-way rental across three
  countries, which is where the drop-off fee comes from` because a £665 rental
  invites a question. The fuel gets nothing, because it does not.
- **Sweep up the rest in one line**, categories only, no amounts.
- `Receipts are attached.` `Happy to talk anything through.` `Thanks,` then the
  sender's own first name.

## What the user leaves out, deliberately

Do not add these back:

- The report ID, the line count, the date range, the expense-type coding, the
  billing type.
- Percentages, "which is 59% of the claim", or any other analysis.
- Caveats about the total moving when PeopleSoft converts the foreign-currency
  lines at submission. Raise that with the user in chat if it matters; keep it
  out of the email.
- Justification they did not ask for, such as "it replaced three separate flights".

## Ranking the two largest

Rank on the claimed amounts as they stand, and say so plainly if a mixed-currency
comparison makes the second place a coin toss. On one run the second and third
were €78.47 fuel and £68.06 dinner, about £1 apart at the rate PeopleSoft was
applying, so either was defensible. The user picked the fuel. **Their pick
wins.** Flag the closeness once, in chat, then write what they chose.
